Planilha Leve

Planilha no navegador com fórmulas em português, do jeito do Excel: =SOMA(A1:A10), =SE(B2>0;"ok";"atenção"), =PROCV(...).

fx

Use as setas para andar, Enter ou F2 para editar e Esc para cancelar. Comece uma fórmula com "=" e clique em células para inserir referências; F4 alterna o $.

Funções disponíveis

Argumentos separados por ponto e vírgula e vírgula como separador decimal. Os nomes funcionam com ou sem acento.

Atalhos de teclado
Setas, Tab
Andar pelas células (com Shift, seleciona)
Ctrl + Setas
Pular até a borda dos dados
Enter ou F2
Editar a célula; Enter de novo confirma e desce
Esc
Cancelar a edição
Delete
Apagar o conteúdo da seleção
Ctrl + C / X / V
Copiar, recortar e colar (fórmulas ajustam as referências)
Ctrl + D / R
Preencher para baixo / para a direita
Ctrl + Z / Y
Desfazer / refazer
F4
Durante a edição, alterna A1, $A$1, A$1 e $A1
Ctrl + Home
Ir para A1

No Mac, use Cmd no lugar de Ctrl.
